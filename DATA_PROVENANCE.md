# Public delivery and input data

This repository publishes the streaming/cardinality-sketch/PageRank implementation and its academic report. Original stream-input batch files containing vehicle registration and event-time records are excluded from this public delivery, including from its Git history.

The source notebooks have no saved execution outputs. Supply appropriately authorized local input data to reproduce the stream experiments; the feeder notebooks describe the expected workflow and record format. Recorded benchmark plots and aggregate algorithm results remain in the report.
